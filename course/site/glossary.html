Glossary · 114 terms

Words that might not have stuck

Every dotted word in the module pages is defined here. The tags show which modules use it.

adam
An optimizer (2014) that keeps a running average of each parameter's gradients and scales each step accordingly. Works well with little tuning; AdamW adds weight decay. M0
attention
Computing a weighted average over many vectors, where the weights come from how well each one matches a query. M2
autograd
PyTorch's automatic differentiation: it records your computation and computes every gradient for you when you call loss.backward(). M0
backpropagation
Computing every weight's gradient by applying the chain rule from the loss backwards through the layers. M0 M1
baseline
A simple reference method you must beat for a new method to be worth anything. Also what every SOTA eventually becomes. M5
benchmark
A shared public test set and metric that everyone reports, such as ImageNet top-5 error. M0
bert
Bidirectional Encoder Representations from Transformers (2018): an encoder trained by filling in masked words. M2
bias
A learned constant added to a neuron's weighted sum. It lets the decision line shift away from the origin. M1
bottleneck
A narrow point everything must squeeze through. In seq2seq, one fixed-size vector for the whole sentence. M2
bpe
Byte-pair encoding: build a vocabulary by repeatedly merging the most frequent adjacent pair of symbols, giving sub-word tokens. M2
bptt
Backpropagation through time: unroll an RNN over the sequence and backpropagate through every step. M2
bradley–terry
A model of pairwise contests: P(A beats B) = σ(score_A − score_B). M4
causal mask
Blocking each position from attending to later positions, so the model can only use the past to predict the next token. M2
cell state
An LSTM's long-term memory lane. It is updated by multiply-and-add, so information (and gradients) can travel far. M2
chinchilla
DeepMind's 2022 compute-optimal model and paper: train on about 20 tokens per parameter. M5
cnn
Convolutional neural network: stacks of convolutions that learn their own image features. M1
context window
The maximum number of tokens a model can read at once. M5
convolution
Sliding a small filter across an image and recording how strongly each location matches it. M1
cross-entropy
The standard classification loss: minus the log of the probability the model gave to the right answer. M0 M2
data augmentation
Creating extra training examples by changes that keep the label, such as flipping or cropping a photo. A cheap defense against overfitting. M0
decoder
The part of a model that generates the output, one token at a time. M2
decoder-only
A Transformer with only a causal decoder, trained to predict the next token. GPT, LLaMA and Qwen are all decoder-only. M2
diffusion model
A generator that learns to remove noise step by step, and creates samples by denoising pure noise. M3
discriminator
In a GAN, the network that tries to tell real samples from generated ones. M3
dot product
Multiply two lists of numbers position by position and add up the results. Large when the lists point the same way, so it works as a similarity or match score. M0 M1 M2
dpo
Direct Preference Optimization (2023): train on preference pairs with a simple loss, with no separate reward model and no RL loop. M4
embedding
A learned vector of numbers that represents a token or item, positioned so that similar things are close together. M2 M4
encoder
The part of a model that reads the input and turns it into internal vectors. M2
epoch
One full pass over the training set, in mini-batches. The usual unit for how long a model trained. M0
feature engineering
Hand-designing the measurements, or features, a model looks at, instead of letting it learn them. M1
few-shot
Giving a model a few worked examples in the prompt before the real question. M4
filter
A small grid of learned weights, such as 5×5×3, that a convolution slides over an image to detect a pattern. M1
fine-tuning
Continuing to train a pretrained model on your own, smaller dataset. M4
flashattention
An exact attention algorithm that works in tiles in on-chip SRAM, so it never writes the n×n score matrix to main memory. M5
flops
Floating-point operations: the unit of compute. Training costs about 6 × parameters × tokens. M5
gan
Generative adversarial network: a generator and a discriminator trained against each other. M3
gate
A learned value between 0 and 1 that multiplies a signal, deciding how much of it passes. M2
generator
In a GAN, the network that turns random noise into fake samples. M3
genetic algorithm
A search that imitates evolution: keep a population of candidate solutions, mutate and recombine them, and keep the fittest. It needs no gradient, but it scales poorly as the number of knobs grows. M0
gradient
For every parameter, how much the loss would change if you nudged it. It points uphill, so training steps the other way. M0
gradient clipping
Scaling the gradient down when its size exceeds a threshold, so one bad step cannot blow up training. M2
gradient descent
Repeatedly nudging every parameter a small step against its gradient so the loss goes down. M0
hbm
High-bandwidth memory: the GPU's main memory. Large, but slow compared with on-chip SRAM. M5
hidden layer
A layer between the input and the output whose values aren't given by the data. The network invents them. M1
hidden state
An RNN's fixed-size running summary of everything it has read so far. M2
hog
Histogram of Oriented Gradients (2005): for each small cell of an image, a histogram of edge directions. M1
hybrid model
A model that mixes a few full-attention layers with many linear-time layers to get both recall and speed. M5
hyperparameter
A setting you choose rather than learn: learning rate, batch size, number of layers, epochs. Chosen by looking at the validation set. M0
imagenet
A dataset of about 14 million labeled photos. Its 1000-class challenge (ILSVRC, 2010–2017) was the benchmark of the deep-learning revolution. M1
in-context learning
A model picking up a task from examples or instructions in its prompt, with no weight updates. M4
initialization
How the starting weights are chosen (usually random, with a carefully picked scale) so that signals neither shrink nor explode at the start. M1
int4
A 4-bit integer: 16 possible values, −8 to 7. Each weight is stored as one of those times a shared scale. M4
kernel trick
Computing similarities as if the data had been lifted into many more dimensions, without ever lifting it, so a linear method can draw curved boundaries. M1
kv cache
The stored keys and values of all previous tokens, kept during generation so they are not recomputed. It grows with context. M5
layernorm
Normalize a vector by subtracting its mean and dividing by its standard deviation, then rescale with learned weights. M2
learning rate
The step size in gradient descent. Too big and training blows up; too small and it crawls. M0
linear attention
An attention variant without softmax that carries a fixed-size running state, so cost grows linearly with length. M5
linear classifier
A classifier whose decision boundary is a straight line, or a flat plane in more dimensions. M1
linearly separable
Two classes that one straight line (or flat plane) can split perfectly. M1
logits
The raw scores a model outputs, one per class (or per vocabulary token), before softmax turns them into probabilities. M0 M4
lora
Low-Rank Adaptation: freeze the model and train a small low-rank update BA added to chosen weight matrices. M4
loss
A single number that measures how wrong the model is on some examples. Training tries to make it smaller. M0
lstm
Long short-term memory (1997): an RNN with a protected cell state and learned gates, so it can remember over long spans. M2
margin
The width of the empty street between an SVM's boundary and the nearest points of each class. M1
matrix multiply
Many dot products at once: every row of the first matrix against every column of the second. (32 × 64) · (64 × 10) gives (32 × 10). M0
mini-batch
A small random slice of the training examples (say 32) used for one gradient step. Noisy but cheap, so you can take many steps. M0
mode collapse
A generator producing only a few kinds of output and ignoring the rest of the data. M3
model
A program whose logic you don't write by hand: a fixed template of simple math (multiply, add, repeat) with millions of blank numbers, filled in automatically from examples. It maps inputs to outputs, such as pixels to a digit or text to the next word. M0
moe
Mixture of experts: many expert sub-networks plus a router that activates only a few per token. M4
n-gram
A language model that predicts the next token by counting what followed the previous n−1 tokens in the training text. M2
nats
A unit for measuring surprise, like bits but using the natural log (1 nat ≈ 1.44 bits). A loss of 1.5 nats per character means the model is about as unsure as choosing among e¹·⁵ ≈ 4.5 equally likely characters. M2
needle in a haystack
A test that hides one fact at some depth in a long text and asks the model to retrieve it. M5
online softmax
Computing a softmax in one streaming pass by keeping a running max and running sum, and rescaling as new values arrive. M5
optimizer
The rule that turns gradients into parameter updates: plain SGD, or adaptive rules like Adam. M0
overfitting
When a model memorizes its training examples, including their noise, and does worse on new data. M0
overtraining
Training a model on far more tokens than the compute-optimal (Chinchilla) amount. It costs more to train and less to serve. M5
parameter
One tunable number inside a model, usually a weight or bias. Training searches for good values. GPT-3 has 175 billion of them. M0
perplexity
e raised to the loss: how many equally likely options the model is effectively choosing between at each step. Lower is better. M2
position encoding
Information added to tokens so attention, which is otherwise order-blind, knows where each one sits. M2
power law
y = a·x⁻ᵅ: a straight line on log–log axes. Each 10× in x improves y by the same factor. M5
ppo
Proximal Policy Optimization: the reinforcement-learning algorithm classic RLHF uses to push the LLM toward higher reward. M4
quantization
Storing numbers in fewer bits (for example 4-bit integers instead of 16-bit floats) to save memory and time. M4
reference model
A frozen copy of the starting model. RLHF and DPO penalize drifting too far from it. M4
relu
max(0, x): negative inputs become 0 and positive inputs pass through unchanged. Its slope is 1 wherever it is active. M1
residual connection
A shortcut that adds a block's input to its output (x + f(x)), so the block only has to learn a correction. M1
resnet
Residual Network (2015): the CNN that used residual connections to train 152 layers. M1
reward model
A model trained to predict which of two answers people prefer. It gives each answer a score. M4
rlhf
Reinforcement learning from human feedback: tune a model to score well with a reward model trained on human preferences. M4
rmsnorm
Like LayerNorm, but only divides by the root-mean-square. No mean subtraction, so it is cheaper. M2
rnn
Recurrent neural network: reads a sequence one step at a time, updating a hidden state. M2
rope
Rotary position embedding: rotate queries and keys by position-dependent angles so attention depends on relative position. M2
router
In an MoE layer, a small learned layer that decides which experts each token goes to. M4
scaling law
An empirical formula predicting loss from model size, data and compute. M5
self-attention
Attention where every position in a sequence attends to every other position of the same sequence. M2
shape
The size of each axis of a tensor, such as (32, 3, 32, 32) for 32 color images of 32 × 32 pixels. The first axis is usually the batch. M0
sift
Scale-Invariant Feature Transform (1999): a hand-designed 128-number descriptor of the edge directions around an image point. M1
sigmoid
The S-shaped function 1/(1+e⁻ˣ), which squashes any number into (0, 1). Its slope is at most ¼. M1
smoothing
Giving unseen events a little probability so the model is never infinitely surprised. M2
softmax
Turns a list of scores into positive weights that sum to 1. Bigger scores get exponentially more weight. M0 M2
sparse
Mostly empty. With long contexts, most combinations never appear in training, so their counts carry no information. M2
sram
The GPU's small, very fast on-chip memory, a few tens of MB in total. M5
state of the art
The best published result on a benchmark right now. Often shortened to SOTA. M0
state-space model
A sequence model (S4, Mamba) that updates a fixed-size state with structured linear dynamics, trainable in parallel. M5
support vectors
The training points that sit on the margin's edges. They alone determine an SVM's boundary. M1
svm
Support vector machine: a classifier that picks the separating boundary with the widest margin. M1
swiglu
A gated MLP activation: Swish(xW) ⊙ xV. Used in LLaMA, Qwen, PaLM and others. M2
tensor
An n-dimensional array of numbers: a vector is 1-D, a matrix 2-D, a batch of color images 4-D. M0
test set
Held-out examples looked at once, at the end, to report how well the model really does. M0 M5
token
One unit of text a model reads: a character, a word, or (usually) a sub-word piece. M2
tokenizer
The code that splits text into tokens and maps each one to an integer ID. M2 M4
training set
The examples the model learns from. M0
transformer
The 2017 architecture built from self-attention and per-position MLPs, with no recurrence. It underlies today's LLMs. M2
validation set
Held-out examples used to choose settings (size, learning rate, when to stop). Not used for the final score. M0
vanishing gradient
The learning signal shrinking toward zero as it is sent back through many layers or time steps, so early parts stop learning. M1
