A first ML course · for software developers · self-paced

You were state of the art. Now you're a baseline.

Baseline is a 4-minute music video that walks through more than thirty machine-learning techniques in order, from the 1958 perceptron to attention and its linear-time successors, each one replaced by the next. This course uses it as a syllabus. Every module pairs a section of the film with the ideas behind it and a Jupyter lab where you build them.

How it works

Watch the section of the film (each module links to its timestamp). Read the module page: every concept is anchored to a still from the film, so you always know where you are. Run the lab notebook: you build each technique yourself, at a size that fits your machine, and see the same kind of real numbers the film puts on screen.

No ML background is assumed. You need to read Python and be comfortable at a terminal. The math is shown, but each idea is also explained in code.

Setup

You need Python 3.11+ and uv. From the repository root:

cd course
uv sync                         # torch, transformers, scikit-learn, jupyterlab …
uv run jupyter lab notebooks/   # open 00_the_loop.ipynb first

Each notebook detects your hardware and picks a tier. Every lab reads its model sizes from that tier, so the same notebook runs everywhere:

TierDetected whenWhat you getDownloads
laptopanything else (CPU, or a base Apple-silicon GPU)small nets, data subsets, Qwen2.5-0.5B. Each lab runs in minutes; tested on CPU.≈ 2.5 GB
mac-maxApple MPS with ≥ 32 GB unified memorywider and deeper nets, full CIFAR-10 with residual blocks, Qwen2.5-1.5B, 16K-token haystacks≈ 5 GB
cudaNVIDIA GPU with ≥ 12 GB VRAMbiggest configs, Qwen2.5-7B in bf16, 32K-token haystacks≈ 17 GB

To force a tier or device, set it before launching: BASELINE_TIER=laptop BASELINE_DEVICE=cpu uv run jupyter lab notebooks/. The sizes live in one table, TIERS in notebooks/blcourse.py, so change it if you want to experiment.
